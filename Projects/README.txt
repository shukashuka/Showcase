Cara pakai folder ini:

1. Buat 1 folder untuk setiap project, nama folder = nama project yang
   akan tampil di website (contoh: "Logo Kopi Senja", "Poster Konser").
2. Taruh semua foto project itu di dalam folder tersebut (jpg/png/webp/gif).
3. Commit & push ke GitHub. Website akan otomatis membaca isi folder ini
   lewat GitHub API — TIDAK perlu edit kode apapun.
4. Repo GitHub kamu harus PUBLIC supaya GitHub API bisa diakses gratis
   tanpa login (lihat GUIDE.md).

3 folder contoh (Project-A, Project-B, Project-C) sudah dibuat sebagai
placeholder — hapus atau ganti isinya dengan foto asli kamu, ganti juga
nama foldernya sesuai project kamu.
